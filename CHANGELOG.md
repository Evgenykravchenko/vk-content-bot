# Changelog

Notable changes are recorded in GitHub Releases generated from Conventional Commits.

## 0.6.0 — 2026-10-29

- Передача с Яндекс Диска во VK измеряется для фото, видео и документов: процент, сглаженная скорость и оценка оставшегося времени отправляются в BotCRM.
- Обновления объединяются и отправляются раз в три секунды; временные ошибки телеметрии не прерывают загрузку. Исходный файл передаётся потоком и не сохраняется на сервере.
- По окончании передачи показывается отдельный этап подтверждения без выдуманного таймера. Поздние обновления прогресса не затирают итоговый статус.
