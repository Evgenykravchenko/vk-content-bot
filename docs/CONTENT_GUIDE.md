# Как настроить выдачу контента в BotCRM

Эта инструкция рассчитана на редактора. Для работы не нужны Docker, API, Directus или доступ к серверу.

Откройте BotCRM и перейдите в раздел **Автоответы**. В верхней части страницы выберите нужного бота. Каждый бот видит только собственные правила и материалы.

## Что есть на странице

- **Автоответы** — фразы пользователей и готовые ответы на них.
- **Медиатека** — фото, видео, аудио и документы с Яндекс Диска.
- **Если ничего не найдено** — сообщение по умолчанию.
- **Так увидит пользователь** — предварительный вид сообщения, медиа и кнопок.

## Текстовый ответ

1. Нажмите **Новый автоответ**.
2. В поле **Ключевая фраза** напишите сообщение пользователя, например `доставка`.
3. В поле **Как распознать** обычно выбирайте **Сообщение содержит фразу**.
4. Напишите текст в разделе **Что получит человек**.
5. Включите **Опубликовать** и сохраните.

Изменение начинает работать без выпуска новой версии бота. Список правил обновляется не дольше 30 секунд.

## Ответ с фото или видео

Сначала загрузите оригинал в папку бота на Яндекс Диске. При подключении через папку приложения BotCRM путь выглядит так: **Приложения → bot_crm → vk_content_bot**. Подпапку создаёт CRM при подключении бота; вручную вводить её путь в автоответе не нужно. Публиковать файл по ссылке не нужно.

Если старые материалы пока остаются в другой папке, готовое видео или фото продолжает отправляться по сохранённому VK ID. Превью и повторная загрузка старого оригинала станут доступны после переноса файла и обновления его пути. Новые файлы добавляйте в папку приложения.

1. В автоответе откройте **Фото, видео и файлы**.
2. Нажмите **Выбрать с Яндекс Диска**.
3. Перейдите в нужную папку и выберите файл. Путь вручную вводить не требуется.
4. Сохраните автоответ.
5. Новый файл сначала проходит состояния **В очереди** и **Обрабатывается**, затем становится **Готов**.

Файл переносится во VK один раз. После подготовки бот использует сохранённый VK ID и не скачивает оригинал при каждой выдаче.

К одному сообщению можно прикрепить не больше 10 медиафайлов. Предпросмотр учитывает вертикальные и горизонтальные изображения и собирает несколько файлов в галерею.

## Ответ с кнопками

В блоке **Кнопки** нажмите **Добавить** и выберите действие:

- **Открыть ссылку** — пользователь перейдёт на сайт; адрес должен начинаться с `https://` или `http://`.
- **Запустить другую фразу** — бот откроет другой автоответ; укажите его ключевую фразу.

Кнопки одной строки автоматически занимают доступную ширину. Их порядок и строки можно менять в редакторе.

## Ответ по умолчанию

Откройте вкладку **Если ничего не найдено**.

- Напишите короткий текст, если достаточно обычного сообщения.
- Выберите полноценный опубликованный автоответ, если нужны фото, видео или кнопки.
- Оставьте оба варианта пустыми, если бот должен молчать при неизвестной фразе.

Полноценный автоответ имеет приоритет над коротким текстом.

## Как распознавать сообщения

| Вариант                         | Когда использовать                | Пример           |
| ------------------------------- | --------------------------------- | ---------------- |
| **Сообщение совпадает целиком** | команда должна быть точной        | `прайс`          |
| **Сообщение содержит фразу**    | фраза может быть частью сообщения | `покажи прайс`   |
| **Есть хотя бы одно слово**     | достаточно одного слова из фразы  | `цена стоимость` |
| **Есть все слова**              | нужны все слова в любом порядке   | `новый каталог`  |

Регистр и обычная пунктуация не важны.

## Важность правила

Оставляйте **Обычную важность** почти всегда. **Выбирать в первую очередь** нужно только когда две фразы могут совпасть одновременно, например `каталог` и `закрытый каталог`.

## Удаление и повторное использование файлов

Файл в медиатеке можно:

- открепить от текущего автоответа;
- использовать в нескольких автоответах;
- удалить из медиатеки, если он больше нигде не прикреплён.

Удаление из медиатеки не удаляет оригинал с Яндекс Диска. Если файл используется в ответе, BotCRM сначала попросит открепить его и сохранить ответ.

## Если файл получил ошибку

Откройте карточку файла и прочитайте причину. Чаще всего файл был переименован, перемещён или удалён с Яндекс Диска. Исправьте источник и снова отправьте материал на подготовку. Токены Яндекс Диска редактору не нужны.

## Проверка перед публикацией

- автоответ опубликован;
- текст заполнен или выбран хотя бы один файл;
- медиа имеет статус **Готов**;
- ссылка кнопки открывается;
- ключевая и заведомо неизвестная фразы проверены в VK.

## Для администратора: подключение бота

У каждого бота есть отдельный секрет `BOTCRM_CONTENT_TOKEN`. Создайте его кнопкой **Токен для бота** в разделе **Автоответы**, скопируйте один раз и добавьте в окружение нужного бота. BotCRM хранит только хеш секрета, поэтому повторно показать полный токен нельзя.

Боту не выдаются адрес Directus и административный токен CMS. Если секрет скомпрометирован, отзовите его в BotCRM и создайте новый — контент остальных ботов останется недоступен.
