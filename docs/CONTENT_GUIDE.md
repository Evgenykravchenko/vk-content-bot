# Как управлять контентом бота

Эта инструкция для человека, который наполняет бота через Directus. Знать Node.js, Docker, API и устройство базы данных не нужно.

Directus открывается по адресу [http://localhost:8055](http://localhost:8055). Войдите с почтой и паролем из `DIRECTUS_ADMIN_EMAIL` и `DIRECTUS_ADMIN_PASSWORD`.

## Главное за минуту

Обычная раздача собирается из трёх частей:

1. **Responses** — что бот должен выдать.
2. **Response Blocks** — текст, фото, видео или файл внутри ответа.
3. **Keywords** — по каким словам этот ответ открывается.

Дополнительно:

- **Media Assets** подготавливает файлы с Яндекс Диска для VK;
- **Response Buttons** добавляет кнопки под ответом;
- **Bot Settings** задаёт ответ на неизвестное сообщение.

![Как связаны разделы Directus](assets/content-model.svg)

> Новую запись в любом списке создаёт кнопка **`+`** в правом верхнем углу. После заполнения нажмите галочку **Save** в правом верхнем углу.

## В каком порядке всё делать

Для ответа без файла:

```text
Responses → Response Blocks → Keywords → проверка в VK
```

Для ответа с фото, видео или документом:

```text
Яндекс Диск → Media Assets → дождаться Ready
→ Responses → Response Blocks → Keywords → проверка в VK
```

Кнопки создаются в конце, когда ответы и ключевые слова для переходов уже готовы.

## Первый обязательный шаг: сообщение «ничего не найдено»

Откройте **Bot Settings**. Здесь есть два варианта.

### Простой текст

В поле **Unknown Message** напишите, например:

```text
Не нашёл такой материал. Напишите «каталог», чтобы посмотреть доступные разделы.
```

Поле **Fallback Response** оставьте пустым и нажмите **Save**.

### Полноценный fallback с фото и кнопками

1. Сначала создайте обычный ответ по одному из рецептов ниже.
2. Поставьте ему **Status = Published**.
3. Ключевое слово для него создавать не обязательно.
4. Вернитесь в **Bot Settings**.
5. В **Fallback Response** выберите созданный ответ.
6. Нажмите **Save**.

Теперь этот ответ будет выдаваться, если ни одно ключевое слово не подошло. Он может содержать текст, медиа и кнопки.

**Fallback Response имеет приоритет над Unknown Message.** Если выбранный fallback остался черновиком или оказался пустым, бот использует **Unknown Message**. Если оба поля пусты, бот отправит встроенный нейтральный текст.

## Рецепт 1. Только текст

Допустим, пользователь пишет `доставка`, а бот должен показать условия доставки.

### 1. Создайте ответ

Откройте **Responses** → **`+`** и заполните:

| Поле              | Что указать                       |
| ----------------- | --------------------------------- |
| **Name**          | `Условия доставки`                |
| **Status**        | `Published`                       |
| **Fallback Text** | `Информация временно недоступна.` |

**Name** видит только редактор. Пользователю оно не отправляется.

### 2. Добавьте текст

Откройте **Response Blocks** → **`+`**:

| Поле                | Что указать                   |
| ------------------- | ----------------------------- |
| **Response**        | `Условия доставки`            |
| **Sort**            | `10`                          |
| **Kind**            | `Text`                        |
| **Body**            | Нужный текст для пользователя |
| **Media**           | оставить пустым               |
| **Send Separately** | выключено                     |
| **Enabled**         | включено                      |

### 3. Добавьте ключевое слово

Откройте **Keywords** → **`+`**:

| Поле           | Что указать        |
| -------------- | ------------------ |
| **Phrase**     | `доставка`         |
| **Match Mode** | `Exact`            |
| **Priority**   | `100`              |
| **Response**   | `Условия доставки` |
| **Enabled**    | включено           |

Сохраните и напишите боту `доставка`. Новое правило может появиться в боте не мгновенно: подождите до 30 секунд.

## Рецепт 2. Текст и фото одним сообщением

Сначала подготовьте фотографию через **Media Assets**. Подробный порядок работы с Яндекс Диском находится [ниже](#как-подготовить-файл-с-яндекс-диска).

Затем:

1. Создайте **Response** со статусом `Published`.
2. Создайте текстовый **Response Block** с `Sort = 10`.
3. Создайте второй **Response Block**:

| Поле                | Что указать                    |
| ------------------- | ------------------------------ |
| **Response**        | тот же ответ                   |
| **Sort**            | `20`                           |
| **Kind**            | `Photo`                        |
| **Body**            | оставить пустым                |
| **Media**           | фотография со статусом `Ready` |
| **Send Separately** | выключено                      |
| **Enabled**         | включено                       |

Когда **Send Separately** выключен у обоих блоков, VK получит один пузырь сообщения: текст и фотографию вместе.

## Рецепт 3. Только фото, без текста

1. Подготовьте фотографию в **Media Assets** и дождитесь `Ready`.
2. Создайте **Response** со статусом `Published`.
3. Добавьте один **Response Block** с `Kind = Photo`.
4. В **Media** выберите готовую фотографию.
5. Поле **Body** оставьте пустым.
6. Создайте **Keyword** и свяжите его с ответом.

Бот отправит только вложение.

## Рецепт 4. Сначала текст, затем отдельное фото

Создайте два блока:

| Sort | Kind    | Send Separately | Результат                  |
| ---: | ------- | --------------- | -------------------------- |
| `10` | `Text`  | выключено       | первое сообщение с текстом |
| `20` | `Photo` | включено        | второе сообщение с фото    |

Флажок **Send Separately** у медиа-блока отделяет его от предыдущего содержимого.

Точно так же можно отправить отдельным сообщением видео, аудиофайл или документ.

## Рецепт 5. Несколько текстовых частей

Добавьте несколько блоков `Text` и управляйте порядком через **Sort**:

- заголовок — `10`;
- описание — `20`;
- предупреждение — `30`.

Если **Send Separately** выключен, части объединятся в одно сообщение через пустую строку. Если включён — соответствующий блок уйдёт отдельно.

Используйте шаг `10`, чтобы позже можно было вставить новый блок между существующими, например `15`.

## Рецепт 6. Ответ с кнопками-командами

Кнопка-команда запускает другое ключевое слово. Сначала создайте ответы, между которыми пользователь будет переходить.

Пример:

- ответ `Главное меню` открывается по слову `меню`;
- ответ `Цены` открывается по слову `цены`;
- ответ `Доставка` открывается по слову `доставка`.

Для ответа `Главное меню` откройте **Response Buttons** → **`+`**:

| Поле           | Кнопка 1       | Кнопка 2       |
| -------------- | -------------- | -------------- |
| **Response**   | `Главное меню` | `Главное меню` |
| **Label**      | `Цены`         | `Доставка`     |
| **Action**     | `Text`         | `Text`         |
| **Target**     | `цены`         | `доставка`     |
| **Color**      | `Primary`      | `Secondary`    |
| **Row Number** | `1`            | `1`            |
| **Sort**       | `10`           | `20`           |
| **Enabled**    | включено       | включено       |

**Label** — надпись, которую видит пользователь. **Target** — существующая ключевая фраза, которую бот должен открыть.

Кнопки с одинаковым **Row Number** стоят в одной строке. Допустимо до пяти кнопок-команд в строке и до шести строк.

## Рецепт 7. Кнопка со ссылкой

В **Response Buttons** создайте запись:

| Поле           | Что указать                     |
| -------------- | ------------------------------- |
| **Response**   | ответ, под которым нужна кнопка |
| **Label**      | `Открыть сайт`                  |
| **Action**     | `Open Link`                     |
| **Target**     | `https://example.com/catalog`   |
| **Row Number** | `1`                             |
| **Sort**       | `10`                            |
| **Enabled**    | включено                        |

Ссылка должна начинаться с `https://` или `http://`. Кнопка-ссылка занимает отдельную строку; её цвет определяет VK.

## Рецепт 8. Кнопки без фото

Фото для кнопок не требуется. Создайте обычный текстовый ответ, затем добавьте к нему записи в **Response Buttons**. Клавиатура появится под последним сообщением ответа.

## Рецепт 9. Фото и кнопки вместе

1. Подготовьте фото в **Media Assets**.
2. Создайте ответ.
3. Добавьте текстовый и фото-блоки.
4. Добавьте кнопки, выбрав тот же **Response**.
5. Опубликуйте ответ и создайте ключевое слово.

Кнопки всегда прикрепляются к последнему сообщению ответа. Если фото отправляется отдельно последним, кнопки окажутся под сообщением с фото.

## Как подготовить файл с Яндекс Диска

### Шаг 1. Загрузите оригинал

На Яндекс Диске создайте понятную структуру, например:

```text
/VK Bot/
├── photos/
│   └── autumn-sale.jpg
├── videos/
│   └── welcome.mp4
└── documents/
    └── price.pdf
```

Папку публиковать по ссылке не нужно. Бот читает закрытый Диск через OAuth-токен.

### Шаг 2. Скопируйте точный путь

Для примеров выше пути будут такими:

```text
/VK Bot/photos/autumn-sale.jpg
/VK Bot/videos/welcome.mp4
/VK Bot/documents/price.pdf
```

Путь начинается с `/`, содержит имя файла и расширение. Регистр букв должен совпадать.

### Шаг 3. Создайте Media Asset

В Directus откройте **Media Assets** → **`+`**:

| Поле            | Что указать                              |
| --------------- | ---------------------------------------- |
| **Name**        | понятное название для редактора          |
| **Kind**        | `Photo`, `Video`, `Audio` или `Document` |
| **Yandex Path** | полный путь с предыдущего шага           |
| **Status**      | сначала `Draft`                          |

Сохраните запись. Затем поменяйте **Status** на `Queued` и снова сохраните.

### Шаг 4. Дождитесь Ready

Статусы меняются так:

```text
Draft → Queued → Processing → Ready
```

- **Draft** — запись ещё редактируется;
- **Queued** — файл ждёт обработки;
- **Processing** — бот переносит файл во VK;
- **Ready** — файл готов к многократной выдаче;
- **Error** — подготовка не удалась.

Проверка очереди выполняется примерно раз в 20 секунд. Видео дополнительно обрабатывается на стороне VK, поэтому может занять больше времени.

Поля **VK Attachment**, **MIME Type** и **File Size** заполняются автоматически. Не редактируйте их вручную.

### Шаг 5. Подключите файл к ответу

Создайте **Response Block**, выберите нужный **Kind**, а в поле **Media** — подготовленный материал со статусом `Ready`.

После `Ready` бот не скачивает файл с Яндекс Диска при каждом запросе. Он отправляет сохранённое вложение VK. Оригинал можно оставить на Диске как архив; он снова понадобится, если материал придётся загружать во VK заново.

## Если Media Asset получил Error

1. Откройте запись.
2. Прочитайте **Error Message**.
3. Проверьте точность **Yandex Path** и наличие файла на Диске.
4. Убедитесь, что выбран правильный **Kind**.
5. После исправления снова поставьте **Status = Queued**.

Если ошибка повторяется, передайте администратору текст из **Error Message**. Токен Яндекс Диска редактору видеть или копировать не нужно.

## Как работают ключевые слова

### Какой Match Mode выбрать

| Режим в Directus | Когда использовать                | Пример                                                 |
| ---------------- | --------------------------------- | ------------------------------------------------------ |
| **Exact**        | команда должна совпасть целиком   | `прайс` сработает только на `прайс`                    |
| **Contains**     | фраза может быть частью сообщения | `покажи прайс` сработает на `пожалуйста, покажи прайс` |
| **Any Word**     | достаточно любого слова из списка | `цена стоимость` сработает на `какая стоимость`        |
| **All Words**    | нужны все слова, порядок не важен | `новый каталог` сработает на `покажи каталог новый`    |

Регистр и обычная пунктуация не важны: `ПРАЙС`, `прайс!` и `прайс` распознаются одинаково.

### Для чего Priority

Если подходят несколько правил, побеждает большее значение **Priority**. Обычно оставляйте `100`.

Повышайте приоритет только для исключений. Например:

- `каталог` — `100`;
- `закрытый каталог` — `200`.

При одинаковом приоритете побеждает более длинная ключевая фраза.

## Два разных fallback-поля — не перепутайте

| Где находится                        | Когда используется                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| **Bot Settings → Unknown Message**   | ни одно ключевое слово не подошло                                            |
| **Bot Settings → Fallback Response** | ни одно ключевое слово не подошло; можно выдать полноценный ответ            |
| **Responses → Fallback Text**        | ключевое слово подошло, но у ответа нет ни одного готового включённого блока |

Для нового ответа полезно заполнять **Fallback Text**, например: `Материал временно недоступен. Попробуйте позже.` Это страхует от пустой отправки при выключенных блоках.

## Как временно скрыть контент

Не удаляйте рабочие записи без необходимости:

- выключите **Keyword → Enabled**, чтобы команда перестала находиться;
- поставьте **Response → Status = Draft**, чтобы ответ не выдавался;
- выключите **Response Block → Enabled**, чтобы скрыть один блок;
- выключите **Response Button → Enabled**, чтобы скрыть одну кнопку.

Так содержимое можно вернуть без повторного заполнения.

## Проверка перед публикацией

Пройдите короткий чек-лист:

- [ ] у ответа выбран `Published`;
- [ ] есть хотя бы один включённый блок или заполнен `Fallback Text`;
- [ ] у медиа статус `Ready`;
- [ ] у ключевого слова включён `Enabled`;
- [ ] ключевое слово связано с правильным ответом;
- [ ] `Target` кнопки-команды совпадает с существующим ключевым словом;
- [ ] ссылка начинается с `https://`;
- [ ] проверены подходящее и заведомо неизвестное сообщения в VK.

## Быстрая диагностика

### Изменения не появились сразу

Подождите до 30 секунд: список ключевых слов кешируется. Текст и состав ответа обычно обновляются сразу после следующего запроса.

### Вместо файла написано «материал пока подготавливается»

Откройте **Media Assets**. Используемый файл ещё не перешёл в `Ready` либо получил `Error`.

### Бот ничего не отправил

Проверьте **Status** ответа, **Enabled** у блоков и заполните **Fallback Text**.

### Кнопка-команда открывает не тот ответ

В **Response Buttons → Target** должно находиться ключевое слово, а не название ответа из **Name**.

### Кнопка не появилась

Проверьте **Enabled**, длину **Label** до 40 символов и корректность `http://` или `https://` для ссылки.
